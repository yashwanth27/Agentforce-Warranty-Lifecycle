# Documentation

Three self-contained HTML documents. Open any of them directly in a
browser — no server, no build step, no internet connection needed.

| File | What it is |
|------|------------|
| `WarrantyDesk-Technical-Reference.html` | 17 sections covering every field, class, permission, queue and agent instruction, with the reasoning behind each. **Start here.** |
| `WarrantyDesk-Execution-Trace.html` | Six end-to-end journeys traced call by call, from the customer's first message to the database write |
| `WarrantyDesk-Call-Graph-Explorer.html` | Interactive graph — click any node to see what calls it and what it calls |

If you're reading this on GitHub, the HTML won't render in the file
preview. Either clone the repo and open the files locally, or enable
GitHub Pages on this repository and browse to `/docs/`.
